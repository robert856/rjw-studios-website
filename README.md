# RJW Studios Website

Responsive portfolio website for RJW Studios, preserving the uploaded original design.

## Local preview

Open `index.html` in your browser, or serve the folder with a static server (for example, `python -m http.server 8000`) and visit http://localhost:8000.

## Files

- `index.html` — website HTML, styles and scripts.
- `assets/` — locally bundled images and videos extracted from the original HTML.

## Notes

This is a static website. Any contact form or other interactive feature requiring a backend should be tested before publishing.
